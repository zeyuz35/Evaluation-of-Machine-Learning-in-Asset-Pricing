## 2024-06-08 - I(vector("list", N)) for data.frame list-column assignment
**Learning:** In R, when initializing a `data.frame` with a column meant to hold lists (e.g., arrays or series of different lengths), using `target = c(1:N)` and subsequently assigning `target[i] <- list(values)` will cause a silent type coercion warning/error or unexpected flattening. To properly handle list-columns, the column must be initialized as `I(vector("list", N))` inside `data.frame()`, and assignment should be done via double brackets: `target[[i]] <- values`.
**Action:** Replaced instances of `target = c(...)` and `target[i] <- list(...)` with `target = I(vector("list", ...))` and `target[[i]] <- ...` across `R/AWS/sagemaker_run.R`, `R/AWS/sagemaker.R`, `R/AWS/json.Rmd`, and `R/aws_prep.Rmd`.
