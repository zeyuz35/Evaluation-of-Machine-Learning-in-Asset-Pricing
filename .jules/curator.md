## 2024-06-04 - Fix silent type coercion when creating list-columns in data.frames
**Learning:** In R, initializing a column with a basic numeric vector `c(1:N)` and subsequently assigning list elements to it using single brackets `df$col[i] <- list(...)` causes silent data coercion. The data inside the list gets flattened or manipulated improperly because the column was not initialized as a list-column. To properly initialize a list-column within `data.frame()`, one must use `I(vector("list", N))`. Further, to assign elements into the list-column, double bracket subsetting `df$col[[i]] <- ...` should be used instead of `df$col[i] <- list(...)` or `df[i, ]$col <- list(...)` to avoid creating unintended nested lists or flattened vectors.
**Action:** When creating a list column in a dataframe, initialize it with `I(vector("list", N))` and use `[[` indexing to insert items, assigning the actual item instead of a wrapped `list(item)`. I have applied this fix across `R/AWS/sagemaker.R`, `R/AWS/sagemaker_run.R`, `R/AWS/json.Rmd`, and `R/aws_prep.Rmd`.
