## 2024-05-01 - [Data Frame List-Column Initialization Fix]
**Learning:** In R, initializing a data frame column with an atomic vector (e.g., `c(1:N)`) and later assigning a list to a single element of that column using single brackets (e.g., `df$target[i] <- list(...)`) silently flattens the list and attempts to coerce it into the atomic vector, leading to corrupted or unexpected shapes. Instead, we must initialize the column correctly as a list using `I(vector('list', N))` to protect it as an 'AsIs' list column, and then assign elements safely using double brackets (e.g., `df$target[[i]] <- ...`).
**Action:** When inspecting code that dynamically builds list columns in data frames inside loops, verify that the column is initialized with `I(vector('list', length))` and populated with `[[i]]` double brackets to avoid type coercion and ensure data integrity.
