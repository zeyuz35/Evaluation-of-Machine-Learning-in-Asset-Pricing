## 2024-06-04 - Fix list-column assignments causing silent flattening
**Learning:** In R, assigning a `list()` to a single element of an atomic numeric vector (e.g., `df$target[i] <- list(value)` where `target` is initialized as `1:N`) causes silent type coercion and data flattening. To safely create list-columns within a `data.frame()` call, the initialization should be wrapped in `I()` (e.g., `target = I(vector("list", N))`). When assigning elements iteratively, use double brackets `df$target[[i]] <- value` (ensuring to remove the `list()` wrapper from `value` to avoid unintended nested lists).
**Action:** When working with list-columns in R data frames, initialize them properly with `I(vector("list", N))` and update assignments to use `[[i]]` instead of `[i]` with a wrapped list, to preserve the complex data structure of the column elements.
