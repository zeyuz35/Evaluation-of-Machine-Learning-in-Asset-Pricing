## 2024-05-31 - Safe list-columns creation in data.frame
**Learning:** In R, when initializing a list column inside `data.frame()`, passing an atomic vector like `target = c(1:cross_units)` and then updating an element to a list like `df$target[i] <- list(value)` causes silent type coercion and data flattening. It is critical to use `I(vector("list", cross_units))` to correctly initialize list columns and then update with `df$target[[i]] <- value` (dropping the list wrapper from the assigned value) or keep `df$target[i] <- list(value)`. However, the memory file indicated `df$target[[i]] <- value`.
**Action:** Replace `target = c(1:cross_units)` with `target = I(vector("list", cross_units))` and `dynamic_feat = c(1:cross_units)` with `dynamic_feat = I(vector("list", cross_units))` inside `data.frame()`. Change the update to `pooled_panel_json$target[[i]] <- pooled_panel_filter$rt` and `pooled_panel_json$dynamic_feat[[i]] <- pooled_panel_filter_feature`. This properly preserves the lists structure without silent coercions or list nesting.
