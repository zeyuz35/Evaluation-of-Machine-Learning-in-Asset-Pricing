## 2024-05-24 - Fix silent type coercion in dataframe list column initialization
**Learning:** Initializing data.frame columns as numeric vectors (e.g. `c(1:cross_units)`) and then assigning a list to a specific row (e.g. `df[1, ]$dynamic_feat <- list(...)` or `df$target[i] <- list(...)`) can cause silent type coercion or flattening. The correct way to initialize a list-column in R is using `I(vector("list", N))`. Also assigning to a slice with `df$target[i] <- list(val)` works but creates an inner list structure `List of N -> val, int, int` when the vector was numeric originally. The best pattern is `df$target[[i]] <- val`.
**Action:** Replace `target = c(1:cross_units)` with `target = I(vector("list", cross_units))` and `dynamic_feat = I(vector("list", cross_units))` in data frame creations before iterative assignment. Also ensure assignments use double brackets `df$target[[i]] <- ...` or if using slicing assignment that `df[i, ]$dynamic_feat <- list(...)` works correctly once initialized as a list.
