## 2024-05-24 - Fix Type Instability in List-Column Assignment
**Learning:** In R, initializing a `data.frame` column with a numeric vector (e.g., `target = c(1:N)`) and later attempting to assign a list to a specific element using single brackets (e.g., `df$target[i] <- list(value)`) causes the list to be flattened. This silenty coerces the data type back into an atomic vector or results in data structure loss if the value has a complex structure. Furthermore, using `list()` directly to create a list-column during dataframe initialization also causes issues due to `data.frame`'s standard behavior.
**Action:** When initializing a dataframe that will hold list-columns, use `I(vector("list", N))` (or `I(list())`). When assigning an element to a specific index of a list-column iteratively, use double bracket indexing `df$target[[i]] <- value` and remove the `list()` wrapper around the assigned value. This ensures type stability and prevents silent coercion/flattening of complex data structures.
