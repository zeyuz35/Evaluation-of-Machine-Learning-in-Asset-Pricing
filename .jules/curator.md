## 2024-05-24 - List-columns initialization in R data.frames

**Learning:** Initializing data frame columns with atomic defaults (e.g., `target = 1:N`) and then assigning a list to a single row using single brackets `df$target[i] <- list(...)` causes silent type coercion, data flattening, or errors, which breaks structured data formats like JSON generated by `jsonlite`.

**Action:** Always pre-allocate explicit list-columns using `df$col <- vector("list", N)` and assign single elements using double brackets `df$col[[i]] <- ...` to preserve data structure and class integrity.
