## 2024-05-24 - explicit external package namespacing (corrected)
**Learning:** Found R files polluting the global namespace by using global `library()` or `require()` calls and unqualified functions. Specifically, `R/umap_play.R` imports 9 different libraries including `tidyverse` libraries, and calls their functions directly. I previously attempted to blindly remove `tidyverse` across the entire project which accidentally removed it from Rmd scripts where functions like `read_csv` weren't properly namespaced. RStudio IDE specific config files should also never be tracked or modified.
**Action:** Reverted the bad git commit. Surgically removed global import calls only in `R/umap_play.R` and transformed usages to explicit `pkg::function()` syntax. Also verified the file using `Rscript -e 'parse("R/umap_play.R")'`.
