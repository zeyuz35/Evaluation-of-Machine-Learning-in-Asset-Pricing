## 2024-05-24 - Convert informal print/cat calls to message()
**Learning:** In R scripts, progress updates, structure printing, and general informational logging should use `message()` instead of `print()` or `cat(..., "\n")`. `message()` correctly routes output to `stderr` separating diagnostics from the standard output. When replacing `cat()` with `message()`, explicitly remove the trailing newline character `\n` because `message()` appends one automatically. Complex strings built via `cat()` using comma separation should be combined via `paste()` or `paste0()` when passed to `message()`. Object printing (e.g., `print(data_frame)` or `print(importance_matrix)`) should be preserved, as `message()` does not handle complex S3 print methods cleanly. When editing files with `sed`, ensure modifications are targeted strictly to line numbers that were fully verified in the exploration trace to avoid accidental changes or modifying assumed text.
**Action:** Always prefer `message()` over `print()` or `cat()` for string logging. Remove manual newlines when converting to `message()`. Use string concatenation (`paste0`) if the original `cat()` had multiple arguments. Only replace literal string print statements, leaving object prints untouched. Always verify line contents thoroughly before applying sed replacements.
