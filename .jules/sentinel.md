## 2024-05-24 - Hardcoded RStudio Password in AWS CloudFormation Templates
**Vulnerability:** The AWS CloudFormation templates (`R/AWS/sagemaker_stack.txt` and `R/AWS/template1`) contain a hardcoded password ('rstudio') for the `rstudio` user account, which is created during EC2 instance initialization. This password is set using `echo rstudio | passwd rstudio --stdin`.
**Learning:** This was likely done for ease of setup and access to the RStudio Server hosted on the EC2 instance, without considering the security implications of hardcoding a default, easily guessable password in infrastructure-as-code templates.
**Prevention:** Avoid hardcoding passwords or secrets in configuration files or code. Instead, use secure methods to generate or provide credentials at runtime, such as using AWS Systems Manager Parameter Store, AWS Secrets Manager, or generating a random password during initialization and outputting it securely to the user (e.g., via AWS CloudFormation outputs or secure logging), or prompting the user to change the password upon first login.
